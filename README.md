# Цех № 7 — онлайн

Игра на 2–4 игроков, у каждого свой телефон. Общий цех с конвейерной лентой и у каждого своя мастерская
со станками и верстаком. Один создаёт комнату и получает код из 4 цифр, остальные входят по коду или по ссылке.
Через чужую дверь можно зайти в мастерскую соперника и утащить детали с пола или готовое из станков.

## Как устроено

- `public/` — сама игра: `index.html`, `game.js`, `art.js`.
- `src/worker.js` — сервер на Cloudflare. Ничего не считает, только пересылает сообщения каждого игрока
  остальным в комнате (одна комната — один Durable Object, до 4 игроков).
- Телефон создателя комнаты ведёт общий цех: ленту, детали на полу, события, таймер, раунды и места игроков
  (оранжевый, синий, зелёный, фиолетовый).
- Мастерскую каждый телефон ведёт сам и рассылает её копию остальным. Если кто-то в гостях утаскивает деталь,
  это подтверждает хозяин мастерской; кто не успел — получает «Не успели!».
- Если у кого-то пропала связь, игра встаёт на паузу у всех; продолжить можно и без отключившихся,
  а вернувшийся игрок сам догоняет остальных.

## Запуск на компьютере

```
npm install
npm run dev
```

Откройте <http://localhost:8787> в двух окнах браузера: в одном создайте игру, в другом войдите по коду.
Телефоны в той же Wi-Fi-сети могут зайти по адресу `http://<IP компьютера>:8787`.

## Выложить в интернет (бесплатно)

1. Зарегистрируйтесь на <https://dash.cloudflare.com/sign-up>.
2. Один раз войдите из этой папки: `npx wrangler login` — откроется браузер, нажмите «Allow».
3. `npm run deploy` — в конце будет адрес вида `https://ceh7.<ваше-имя>.workers.dev`.

Бесплатного тарифа Cloudflare хватает примерно на сотню матчей в день.

## Для проверки

- `#debug` в конце адреса открывает отладочный объект `window.__t`.
- `#debug&lag=150` добавляет 150 мс задержки к отправке сообщений.
