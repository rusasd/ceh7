# Цех № 7 — онлайн

Игра на двоих, у каждого свой телефон. Общий цех с конвейерной лентой и у каждого своя мастерская
со станками и верстаком. Один создаёт комнату и получает код из 4 цифр, второй входит по коду или по ссылке.

## Как устроено

- `public/` — сама игра: `index.html`, `game.js`, `art.js`.
- `src/worker.js` — сервер на Cloudflare. Ничего не считает, только пересылает сообщения между двумя игроками
  в комнате (одна комната — один Durable Object).
- Телефон создателя комнаты («хозяин») ведёт общий цех: ленту, детали на полу, события, таймер и раунды.
  Мастерскую каждый телефон считает сам, сопернику уходят только очки.
- Если связь пропала, игра встаёт на паузу у обоих и сама переподключается.

## Запуск на компьютере

```
npm install
npm run dev
```

Откройте <http://localhost:8787> в двух окнах браузера: в одном создайте игру, в другом войдите по коду.
Телефоны в той же Wi-Fi-сети могут зайти по адресу `http://<IP компьютера>:8787`.

## Выложить в интернет (бесплатно)

1. Зарегистрируйтесь на <https://dash.cloudflare.com/sign-up>.
2. Один раз войдите из этой папки: `npx wrangler login` — откроется браузер, нажмите «Allow».
3. `npm run deploy` — в конце будет адрес вида `https://ceh7.<ваше-имя>.workers.dev`.

Бесплатного тарифа Cloudflare хватает примерно на сотню матчей в день.

## Для проверки

- `#debug` в конце адреса открывает отладочный объект `window.__t`.
- `#debug&lag=150` добавляет 150 мс задержки к отправке сообщений.
